ModalosPichulos

Sistema para la gestión de una tienda de ropa.

1. Problema Detectado

En una tienda de ropa el control del stock y las ventas se realiza de forma manual, lo que genera errores en los talles disponibles, pérdida de ventas y desorganización.

2. Propuesta de Valor

El sistema ModalosPichulos permitirá administrar las ventas, el stock y los productos de forma digital, mejorando la organización y la atención al cliente.

3. Tipo de Sistema

Es un sistema TPS con funciones básicas de MIS.

4. Recursos Necesarios

  • Vendedores.
  • Prendas, talles, precios, ventas y stock.
  • Computadora o celular.

5. Modelado Visual

Actor

  • Vendedor.

Casos de Uso

  • Iniciar sesión.
  • Registrar venta.
  • Consultar stock.
  • Registrar prenda.
  • Actualizar precios.
  • Generar reporte.
